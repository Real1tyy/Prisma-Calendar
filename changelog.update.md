### Added

- **Event actions in Obsidian's file menu**: right-clicking a note that Prisma tracks as an event — in the file explorer or from its tab's **More options** menu — now offers **Edit event**, **Trigger stopwatch**, **Mark as done/undone** and **Skip/unskip**, so you can act on an event without switching to the calendar. Plain notes are untouched, the stopwatch entry follows your time-tracker setting, and the whole group can be turned off per planning system in **Settings → General → Interface**. See [File Menu Actions](./features/management/file-menu-actions.md).
