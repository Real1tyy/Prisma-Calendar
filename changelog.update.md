### Added

- **Logs view** — read Prisma's own log without the developer console. Settings → General → Logging → **Open logs** (or the **Open logs** command) opens a live table of what the plugin recorded: filter by level, scope and time interval, search the messages and their structured details, unfold any entry, and switch the source to an earlier session's log file when file logging is on. Copy the filtered rows, or save them into a `Prisma Logs` folder to attach to a bug report — paths and property values are redacted on the way out unless you turn on full detail.
