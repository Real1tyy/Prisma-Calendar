### Added

- **Collapsible calendar header on mobile**: on a phone — or any pane under 768px — the calendar opens with its header collapsed to a single chevron, so the grid gets the whole screen instead of five rows of chrome. Tapping the chevron opens exactly two rows: navigation, **Create**, **Filters** and **Tabs** on the first; the untracked-events menu, **Events**, the date (shortened to fit, like **Nov 4**), **Batch**, the all-day control and **Views** on the second. **Tabs** and **Views** each reveal one more row (the view tabs and the **year / month / week / day / list** switcher) and both start hidden, so anything you don't need costs no space. **Batch Select** reads **Batch** at this width. Nothing changes on desktop. See [Calendar View → Mobile layout](./features/calendar/calendar-view.md#mobile-layout).
- **All-day display modes**: a new **All-day** button in week and day views cycles the all-day strip through three states — the usual capped strip with its **+N more** link, a full-height strip showing every all-day event with nothing hidden or clipped, and no strip at all so the timed grid takes the whole height. The label tells you which one you're in, and the choice lasts until you close the view. Month, year, and list views keep their own **+N more** behavior. Works on mobile and desktop. See [Calendar View → All-Day Display Modes](./features/calendar/calendar-view.md#all-day-display-modes).

### Improved

- **Phone layout, everywhere**: the view tab bar now takes a single row at every width, showing as many tabs as fit and listing the rest behind **⋯** (Dashboard sub-views included); the tab you're on always stays visible. On a phone, the view header shows the capacity figure instead of the calendar's name when capacity tracking is on; the untracked-events menu opens as a full-height panel centred on the screen instead of half off its left edge; search boxes on phones and tablets no longer open the keyboard the moment a menu or dialog opens (creating an event still puts the cursor in its title); and the **Events** dialog fits the screen, with sideways-scrolling tabs, a type filter that stays inside its box, and each event as a card with its buttons underneath. See [Calendar View → Mobile layout](./features/calendar/calendar-view.md#mobile-layout).

### Fixed

- **Mobile events per day: 0 now means unlimited**: setting **Mobile events per day** to 0 did not lift the cap on phones, even though the setting says 0 is unlimited. It now behaves like **Desktop events per day**. See [Calendar UI](./configuration/calendar-ui.md).
