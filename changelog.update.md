### Added

- **Logs view** — read Prisma's own log without the developer console. Settings → General → Logging → **Open logs** (or the **Open logs** command) opens a live table of what the plugin recorded: filter by level, by one or several scopes, and by time interval, search the messages and their structured details, unfold any entry, and switch the source to an earlier session's log file when file logging is on. **Report a bug** in the view's header opens the bug report form with your logs and health checks already attached. **Copy filtered**, **Copy all**, **Save to file** and **Clear buffer** sit beside it, and you can reorder, rename or hide them like any other Prisma header button. Saved exports land in a `Prisma Logs` folder to attach to a report — paths and property values are redacted on the way out unless you turn on full detail.
