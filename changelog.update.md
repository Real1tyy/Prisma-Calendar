### Added

- **Note content in event modals**: create and edit event modals include a full-width plain-text **Note content** field, so agendas, meeting notes, and links can be saved without opening the note separately. The field follows external note edits while it is untouched, warns before overwriting a concurrent edit, participates in undo, and is reachable with the header button or `Ctrl/Cmd+Shift+N`.
