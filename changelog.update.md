### Added

- Report a bug, request a feature or send feedback without leaving Obsidian — from **Settings → General → Send feedback**, or the **Send feedback** command, which you can bind to a hotkey to report a problem while it is still on screen. A bug report attaches the recent warnings, errors and last few minutes of activity by default, you can add screenshots by picking a file or pasting one straight into the modal, and everything attached is shown for review before you send it. On a Pro install the report carries your license key so it can be linked to your account, with a checkbox to opt out. A failed send keeps your text and attachments so you can retry.
